# Project Name: Portfolio Project

## Project Description
This portfolio project is a personal website created to showcase programming projects, technical skills, and web development experience. The website includes dynamic project rendering, persistent storage features, dark mode functionality, and interactive elements.

## Project Tasks
- **Task 1: Create the portfolio structure**
  - Build the webpage using HTML5 structure
  - Create navigation and portfolio sections
  - Add project and skills content

- **Task 2: Add interactivity**
  - Implement JavaScript variables, loops, and conditional statements
  - Add event-driven programming features
  - Create interactive buttons and navigation

- **Task 3: Work with DOM elements**
  - Dynamically create and render project content
  - Use DOM selectors and event listeners
  - Add timing functionality for modal interactions

- **Task 4: Implement persistent storage**
  - Store project data using sessionStorage
  - Retrieve and parse stored data on page load
  - Save user theme preferences with localStorage

- **Task 5: Create scalable foundations**
  - Define custom JavaScript objects for projects
  - Store project objects inside arrays
  - Dynamically render portfolio projects to the webpage

- **Task 6: Finalize and publish**
  - Review the website for functionality and formatting
  - Publish the portfolio using GitHub Pages

## Project Skills Learned
- Dynamic DOM rendering
- JavaScript object creation
- Session storage and local storage
- Event-driven programming
- Portfolio webpage development
- GitHub Pages deployment

## Languages Used
- **HTML**: For webpage structure  
- **CSS**: For webpage styling and responsive design  
- **JavaScript**: For interactivity, DOM rendering, and storage functionality
